# Kaleo website prototype

Static HTML prototype of the Kaleo homepage and the Video Production service page.

- `/` — homepage
- `/services/video-production` — Video Production page

## Deploy on Vercel

Import this repository in Vercel and set **Root Directory** to `kaleo`. Framework preset: **Other**. No build command.

All imagery is AI-generated placeholder content; client names, metrics and copy marked as placeholders need confirmation before going live.
